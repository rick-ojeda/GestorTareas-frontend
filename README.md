# GestorTareas
Esta en una aplicacion en Javascript para gestionar tareas, permite agregar una tarea con fecha de termino, listar las tareas, cambiar el estado de la tarea y eliminar tareas.
Se aplico programacion orientada a objetos, la clase tarea contiene un id, estado, fecha de creacion y fecha de termino, se utilizaron funciones flecha, destructuring, funciones asincronicas al ingresar la tarea para simular un retardo al ingreso de la tarea y un contador regresivo con la fecha actual y la fecha limite de la tarea creada.
Toda la tarea se almacena en localStorage utilizando APIs para acceder a ella.
